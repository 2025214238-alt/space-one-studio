# 공간 한 칸

가구를 배치하고 부위별 색을 바꾸는 2D 주거 공간 설계 게임이에요.

## 게임 열기

https://2025214238-alt.github.io/space-one-studio/

방문자는 로그인이나 승인 없이 게임을 실행할 수 있어요. 배치는 각자의 브라우저에만 저장돼요.
기존 BAZE 주소에 저장했던 디자인은 이 주소로 자동 이전되지 않아요.

## 기능

- 25cm 그리드 스냅과 터치/마우스 드래그 배치
- 가구 회전, 삭제, 부위별 파스텔/비비드/우드톤 색상 변경
- 가구 충돌 및 방 밖 배치 방지, 출입문 동선 경고
- 총 36종 가구와 8가지 시나리오, 가구 검색과 카테고리 필터
- 되돌리기, 다시 실행, 브라우저 자동 저장과 SVG 내보내기

## 개발

`npm install` 후 `npm run dev`로 미리보기를 실행해요.
`node scripts/build-pages.mjs`는 GitHub Pages용 정적 파일을 dist에 만들어요.
GitHub Pages는 gh-pages 브랜치의 루트를 게시해요. 해당 브랜치에는 만들어진 정적 파일만 올려요.
이 정적 게임에는 계정 연결 토큰이나 비밀키가 필요하지 않아요.
기본 템플릿의 관리 화면과 문의 처리는 정적 게임에서 사용하지 않아요.
