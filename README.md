# AI HOUSE SURVIVAL

중학교 2학년 기술·가정 수업용 2D 주거 공간 설계 게임이에요. 기존 ‘공간 한 칸’의 가구 그림과 배치 방식을 확장했어요.

## 게임 열기
https://2025214238-alt.github.io/space-one-studio/

로그인 없이 사용할 수 있어요. **실제 AI를 호출하지 않으며**, 화면의 질문형 학습 코치는 배치 상태와 학생 답변에 맞춰 준비된 질문을 하나씩 골라요. 자동 정답 판정이나 완성 배치를 제공하지 않아요.

## 수업 흐름
1. 수업 미션 모드에서 나만의 집을 만들어요. 기본값은 100㎡이고 새 집 만들기에서 60·100·150㎡와 자유/수업 모드를 선택해요.
2. 최초 설계 완료를 누르면 원본을 보존하고 15가지 생활·진로 변화 중 하나를 무작위로 공개해요. 이후 전체 면적은 고정돼요.
3. 내부 구조와 가구를 바꾸고, 학습 코치의 질문에 답하며 재설계해요. 추천 가구는 정답이 아니고 모든 가구를 계속 사용할 수 있어요.
4. 설계 비교에서 변경 전후를 보고 다섯 가지 학습 기록을 작성해요. 설계 파일과 학습 기록을 직접 내려받아 제출해요.

## 구현된 기능
- 기존 36종을 포함한 286종 가구·소품, 검색·카테고리·크기·배치 위치·즐겨찾기·최근 사용·미션 추천.
- 25cm 격자, 마우스·터치 드래그, 클릭 추가, 선택·이동·회전·복제·삭제, 두 부위 색상 변경, 실행 취소·다시 실행.
- 내부 벽·직사각형 방 그리기, 벽 지우기, 1m 문·창문 설치 및 제거, 구역 이름 변경. 방 크기·형태는 내부 벽을 지우고 다시 그려 조절해요. 외벽은 고정돼요.
- 책상·선반·주방 설비의 상판 소품과 벽 부착형 장식. 받침 가구의 이동·회전·복제·삭제에 소품이 함께 반영돼요. 가스/인덕션 소품은 주방 상판에만 놓을 수 있어요.
- 8종 접이식/확장형 가구는 실제 점유 크기가 바뀌어요. 펼칠 공간이나 상판 소품 공간이 부족하면 상태 변경을 거절해요.
- 겹침·외벽·내부 벽 충돌 방지. 러그·매트는 바닥 장식으로 다른 가구와 함께 놓을 수 있어요.
- 문 앞 차단 경고와 50cm 격자 기반 통로 확인. 건축·접근성·소방 기준에 따른 전문 안전 판정은 아니에요.
- 70~240% 확대·축소, 손 도구·스크롤로 화면 이동.
- 최초 설계와 재설계 비교, 추가·제거·이동·회전·색상/상태 변경 집계. 교체는 제거와 추가로 표시해요.
- 브라우저 자동 저장, JSON 전체 저장/불러오기, 최초·재설계 SVG 이미지 저장, TXT 학습 기록 내보내기.

## 저장과 제한
각자의 브라우저에만 저장돼요. 교사 자동 수합·계정·기기 간 자동 동기화·3D·층별 설계는 없어요. 실제 AI 연결도 이번 범위가 아니에요. 유명 캐릭터의 공식 이미지는 사용하지 않아요.

이전 버전 저장은 `space-one-v1`에 그대로 보존해요. 안내 배너에서 기존 배치를 100㎡ 새 집으로 가져올 수 있어요. 새 형식은 `ai-house-survival-v2`에 별도로 저장해요. 잘못된 파일은 현재 설계를 덮어쓰지 않아요. 손상된 브라우저 저장은 자동 덮어쓰기를 멈추고 안내해요.

현재 집을 새로 만들거나 다른 파일을 불러오기 전에는 **파일 저장**으로 보관해 주세요. 한 집의 한도는 가구·소품 1,000개, 내부 벽 150개, 문·창문 200개, 구역 이름표 100개예요. 실행 취소는 최근 40회예요. 한도는 기기 성능을 보장하는 수치가 아니에요.

## 개발과 검사
`npm install` 후 `npm run dev`로 실행해요. `node scripts/build-pages.mjs`는 GitHub Pages 하위 경로에 맞춘 정적 결과를 만들어요. `gh-pages` 브랜치에서 게시해요. 비밀키는 필요하지 않아요.

- `test/house-engine.cjs`: 286종의 배치·회전·복원, 모든 주택 크기, 상판 연동·주방 안전·면적 잠금·파일 검증 등 검사.
- `test/house-ui.cjs`: 실제 PC·모바일 클릭/터치 드래그, 구조 편집·15가지 미션·비교·다운로드·불러오기·기존 저장 보존 검사. `STUDIO_URL`로 게시 주소도 검사해요.
- `test/house-touch-scroll.cjs`: 모바일 목록을 가구 카드 위에서 밀어 스크롤해도 실수로 배치되지 않는지 검사해요. 모바일에서는 탭으로 추가하고 도면에서 끌어 옮겨요.
- 기존 `test/studio.cjs`, `test/catalog.cjs`는 이전 36종 화면의 기록용 검사예요. 새 UI에는 위의 검사를 사용해요.
- 기본 견본 관리 화면과 문의 처리는 이 게임에서 사용하지 않아요.
